# FlipStuck (Task One)

A modern, responsive landing page for FlipStuck, an online learning platform. 

## Features
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop viewports.
- **Pure HTML & CSS**: Built strictly with HTML and CSS, featuring a JS-free mobile navigation drawer (using the checkbox hack).
- **Infinite Marquee**: Smooth CSS-based infinite scrolling partner logos on mobile devices.
- **Modern UI**: Clean layout, custom typography, and a modern color palette.

## Local Development
To view the project locally, simply open `TaskOne/index.html` in any modern web browser.
No build steps or local servers are required.

## Deployment
This project is configured for seamless deployment on Vercel.
